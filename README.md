# SHAM Athletics — موقع تعريفي

موقع عربي متجاوب بهوية أخضر غامق وأسود، مع حركات ظهور ناعمة وأقسام الأكاديمية والمعدات والفعاليات والحوكمة.

## الملفات
- `index.html` — محتوى الموقع.
- `style.css` — التصميم والألوان والحركات والتجاوب مع الجوال.
- `script.js` — القائمة المتحركة، تأثيرات الظهور، ونموذج التواصل.

## قبل النشر
1. افتح `script.js`.
2. غيّر `CONTACT_EMAIL = ""` إلى البريد الرسمي للجهة بين علامتي الاقتباس.
3. راجع النصوص والخدمات والسياسات لتطابق ما تقدمه SHAM فعليًا.
4. الصور الحالية من Unsplash وتحتاج اتصال إنترنت. استبدلها بصور الأكاديمية المعتمدة عند توفرها.

## النشر عبر GitHub Pages
1. أنشئ مستودعًا جديدًا على GitHub باسم `sham-athletics`.
2. ارفع الملفات الثلاثة إلى جذر المستودع (لا ترفع مجلدًا إضافيًا يحتويها).
3. افتح **Settings → Pages**.
4. تحت **Build and deployment** اختر **Deploy from a branch**.
5. اختر الفرع `main` والمجلد `/ (root)` ثم اضغط **Save**.
6. انتظر قليلًا حتى يظهر رابط الموقع في صفحة Pages.

ملاحظة: النموذج يفتح تطبيق البريد باستخدام `mailto` بعد إضافة البريد. لا يحفظ الطلبات في قاعدة بيانات.
